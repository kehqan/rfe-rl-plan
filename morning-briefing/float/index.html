How It Works

1 Uses the native Document Picture-in-Picture API — built into Chrome 116+ and Edge 116+.
2 Opens a real floating browser window that stays on top of all other apps — no extension, no hack.
3 The floating window contains an iframe loading your target URL at the size you choose.
4 Some sites block iframes. If a site doesn't load, try opening it via a proxy or use a site that allows embedding.
⚠ Requires Chrome 116+ or Edge 116+. Must be triggered by a user gesture (button click). Firefox not supported yet.
